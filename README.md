# Budget Tracker V1

This repository contains the V1 Budget Tracker application.

## Main page

The main application page is `tracker.html`.

## Application pages

- `tracker.html` — Budget Tracker
- `loan.html` — Loan Tracker
- `lend.html` — Interest Tracker
- `analytics.html` — Analytics
- `admin.html` — Administration

## Running locally

Install dependencies and start the Node.js server:

```bash
npm install
npm start
```

The application uses `tracker.html` as its main page.
